# Pizza Dough Calculator

A calculator-only, offline-first PWA for iPad Pro, recreated from the live Dough Guy calculator. Built with React, TypeScript, Vite and vite-plugin-pwa, using the PWA conventions from GAINZ and Daily Task Manager.

## Open the app

https://zankae.github.io/pizza-dough-calculator/

## Install on iPad

1. Open the link in **Safari**.
2. Tap **Share → Add to Home Screen**.
3. Leave **Open as Web App** enabled if that option appears, then tap **Add**.
4. Open the new Home Screen icon while online and wait for **Offline ready**.
5. The calculator now works without Wi-Fi. Your settings are saved on this device.

The initial download needs internet. The app and Safari may have separate storage. Clearing website data or removing the installed app may delete settings/cached files. Safari controls Home Screen installation; no App Store download is needed.

## Features

- Diameter: 10–20 inches; quantity: 1–10 pizzas.
- Thin, regular or thick dough; regular and gluten-free flour modes.
- Live flour, water, yeast, salt, sugar and olive-oil weights with baker's percentages.
- Source-compatible dough-ball estimate, hydration, tips and making instructions.
- Touch-friendly sliders and step buttons; both iPad orientations; phone layout.
- Remembered settings, offline fonts/assets, copy-recipe with a manual fallback, print/save and an in-app update prompt.
- No shopping, account, advertising, tracking scripts or server-side data storage.

**Important:** the source calculator's dough-ball estimate does not necessarily equal ingredient totals divided by quantity, particularly in gluten-free mode. This app deliberately preserves that estimate, labels it clearly, and reproduces the source's ingredient outputs rather than changing the recipe.

## Development

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview -- --port 4173 --strictPort
```

For browser tests against this local-root preview, use `APP_URL=http://127.0.0.1:4173/ npm run test:e2e` after `npx playwright install chromium webkit`.

For exact GitHub Pages subpath verification, **both build and preview must use the same environment**:

```sh
GITHUB_ACTIONS=true GITHUB_REPOSITORY=Zankae/pizza-dough-calculator npm run build
GITHUB_ACTIONS=true GITHUB_REPOSITORY=Zankae/pizza-dough-calculator npm run preview -- --port 4173 --strictPort
npm run test:e2e
```

GitHub Actions runs reproducible installation, unit tests, a production build and Pages deployment on pushes to `main`. It uses relative manifest paths and derives the Vite/service-worker base from the repository name. No credentials are committed.

Icons are original illustrations generated by `scripts/generate_icons.py` (requires Pillow). Fonts are bundled from Fontsource. Formula and recipe reference: https://doughguy.co/pages/dough. Independent app; no affiliation with Dough Guy.
